| 场景 | 操作与观察 |
| --- | --- |
| M1 桌面选座 | 以student登录，选择10月25日09:00–11:00，搜索空间，点静思自习室02号带插座座位，确认后自动进入我的预约；列表显示待签到和正确时段 |

| M2 第一级审批 | 独立浏览器会话以dept-approver登录，默认待我审批能看到该申请；查看并处理→通过审批→确认；院系步骤显示批准、人员和时间 |

| M2 申请人历史与撤销 | applicant刷新列表和详情，看到两级步骤；切换375px，撤销申请对话框完整可操作，填写“独立体验结束，释放教室供实际使用”并确认，状态变为已取消且撤销按钮消失 |

## 视觉与可用性反馈

- 桌面导航、查询、卡片与详情层级清楚；奶白背景与深绿强调统一，座位编号和插座图标可辨认。申请说明、审批步骤与危险操作具有独立间距。
- 375px下详情抽屉宽度适配，按钮没有被裁切；取消/撤销的二次确认位于详情之上，能够直接操作。
