# 业务页面指南

[使用手册](README.md) · [六项工作流](workflows.md) · [管理工作台](administration.md) · [常见问题](faq.md)

本文按真实菜单说明页面。按钮只在当前身份、范围和记录状态允许时出现；看到按钮后提交仍可能因记录刚发生变化而失败。所有日期与时间按中国标准时间显示。

<a id="login"></a>
## 登录

**入口与使用者：** 所有用户打开系统地址，未登录时看到“欢迎回到栖学”；路径为 `/login`。

填“账号”“密码”，点“登录”。成功后进入适合当前权限的首页；退出在右上角姓名菜单的“退出登录”。学校统一开通账号，忘记密码联系管理员，没有自助注册或找回密码按钮。本地演示使用 [统一账号说明](../development/demo-accounts.md)，不能把其他实例的密码照搬过来。

提示账号或密码错误时核对输入及环境；管理员停用、重置密码或调整授权后，可能需要用有效账号重新登录。出现“服务暂时不可用”时点“重新连接”或稍后重试。进入后仍缺菜单，按 [权限问题](faq.md#permission) 处理。

<a id="seats"></a>
## 查找座位

**入口与使用者：** 有选座资格的用户，学习空间 →“查找座位”；路径 `/seats`，页面标题“找一个好位置”。

| 控件 | 怎么用 |
| --- | --- |
| 使用日期、开始时间、专注时长 | 选择将来的完整整点时段，然后点“查找空间”；更改时间后再点一次，才查询新时段 |
| 校区、楼宇、教室 | 缩小位置；切换上级会重置下级选择，清空可放宽筛选 |
| 仅带插座 | 打开后只看带插座的可约座位 |
| 座位按钮 | 点击弹出“确认预约”，核对位置、编号、时间，点“确认” |
| 底部分页 | 切换当前结果页；总数是符合条件的座位数 |

初次进入尚未查询，不代表没有空位。查询成功后按教室展示座位；“这个时段暂时没有空位”时换时间或取消过窄的条件。只显示自己有准入资格的资源，不会显示他人的身份。

确认成功会提示“预约成功，请按时到教室签到”，并进入“我的预约”。开始必须晚于当前时刻，结束在未来 14 天内，整个时段都开放，且本人没有重叠预约。冲突说明提交时条件已变化，返回重新选；查询不会替你保留位置。

从历史“再次预约”进入会显示“已带入上次使用的教室与座位”，历史座位在结果中突出显示。仍要选择新时间并查询，不能复用旧订单状态；若原座位停用或新时段不可用，换可用位置。完整示例见 [选座与签到](workflows.md#booking)。

<a id="reservations"></a>
## 我的预约

**入口与使用者：** 登录用户查看本人记录，学习空间 →“我的预约”；路径 `/reservations`。

“预约记录”可按状态、日期范围筛选，日期按预约开始日期计算，包含所选结束日期整天。点击“刷新”更新列表。“未签到记录”只展示本人的未按时签到记录；不会显示他人记录，也不会据此自动取消预约资格。

打开“查看详情”可看预约编号、教室、座位、时段和取消原因。编号旁复制图标可复制完整编号。“去选座”或“再次预约”在有选座资格时出现。

| 状态 | 含义和下一步 |
| --- | --- |
| 待签到 | 已预约；开始前可“取消预约”。到签到窗口后“立即签到”，填“教室当日签到码” |
| 使用中 | 已签到；正常到结束时系统处理完成，无需点结束按钮 |
| 已完成 | 历史使用记录，可再次预约新时段 |
| 已取消 | 查看取消原因；需要时重新选座，不会自动复活 |
| 未签到 | 超过签到窗口仍未成功签到；座位已按规则释放，可查看未签到记录 |
| 维修中断 | 使用过程中因维修中断；不新增未签到违约 |

签到窗口包含开始时刻，不包含开始后第 15 分钟整点；例如 09:00–09:15 之间允许，09:15 不允许。码从该教室当天屏幕取得，普通预约详情不显示明码。不要猜码反复提交，单账号一分钟最多 5 次签到尝试。开始后不能通过取消绕开未签到；发生维修影响与未签到处理先后时，以保存的历史结果为准。错误下一步见 [签到问题](faq.md#checkin)。

<a id="applications"></a>
## 教室申请

**入口与使用者：** 学习空间 →“教室申请”，路径 `/applications`。有单独申请资格才有“申请教室”；有审批资格才有审批标签。仅有学生角色时可能看到“整教室申请需要单独授权”，已有本人记录仍可查看。

| 标签或入口 | 看什么、做什么 |
| --- | --- |
| 我的申请 | 本人的申请；打开详情查看时段、用途、审批截止和进度，按允许状态撤销 |
| 待我审批 | 当前轮到本人职责且在授权范围内的步骤；“通过审批”或“驳回” |
| 我已处理 | 回看已由本人处理的申请及决定，不等于还可再次批准 |
| 申请教室 | 选时间 →“查找空间”→“选择教室”→填用途标题/用途说明→确认 |

标题 1–100 字，说明 1–2000 字。详情“审批进度”按“院系审批 → 空间审批”显示；第二级尚未开放时为“待前级审批”。“通过审批”意见选填，最多 500 字；“驳回理由”必填 1–500 字。申请人不能自批，同一人不能完成两级；系统管理员身份不能替代审批角色。

| 申请状态 | 含义和下一步 |
| --- | --- |
| 审批中 | 仍未取得教室占用，包括第一级已通过的情况；查看当前步骤与截止 |
| 已批准 | 最终审批成功，占用该时段整间教室；本人仅在开始前可撤销 |
| 未通过 | 查看驳回理由；需要时重新申请 |
| 已过期 | 审批截止已到，不能再通过；重新选择时间申请 |
| 已取消 | 本人、管理人员或维修影响导致取消，详情可见原因 |
| 已完成 | 已批准申请的使用时段结束 |

最终审批遇到占用冲突，不留下本次批准；刷新后在截止前另作决定。审批截止是创建后 24 小时与开始时间的较早者。提交后的用途与时段不能直接编辑，按允许状态“撤销申请”后重建；管理撤销须有范围并填原因。跨角色演示见 [申请与审批](workflows.md#application)。

<a id="repairs"></a>
## 设施报修

**入口与使用者：** 学习空间 →“设施报修”，路径 `/repairs`。本人记录在“我的报修”；维修人员另有“我的维修任务”；派单/物业管理人员另有“工单管理”。各列表点“查看 / 处理”打开工单详情。

有报修资格时点“上报故障”，填故障教室、标题 1–100 字、问题描述 1–2000 字。若“上报故障”暂不可点，先等教室加载；“暂无可报修教室”可“重新加载教室”，仍无结果时联系空间管理员。当前页面不提供照片上传。

| 状态 | 可见动作与结果，实际以本人按钮为准 |
| --- | --- |
| 待派单 | 派单员“派单 / 重新派单”选择维修人员；报修人可“取消工单” |
| 待维修 | 本次被派人员“开始维修”；派单员可改派或取消；开始后不支持转派 |
| 下架同步中 | 显示“正在同步下架，尚未开始维修”；等确认，有权限管理人员可“重试同步” |
| 维修中 | 被派人员“提交完工”，填写“维修处理情况”1–2000 字 |
| 待验收 | 报修人或合格物业管理员“验收通过”或“验收不通过”；实际维修人不可自验 |
| 恢复同步中 | 显示“正在同步恢复，工单尚未关闭”；等确认，不能当已关闭 |
| 已关闭 | 报修人“评价维修”，选择 1–5 分，补充评价最多 500 字，只能提交一次 |
| 已取消 | 终态，不再派单或开修；取消前界面要求填写原因 |

“验收不通过”须说明仍存在的问题，1–500 字；工单退回“维修中”，资源继续下架。“验收通过”意见选填最多 500 字；确认解除本来源后才“已关闭”。待验收期间仍封禁，超时也不自动通过。

详情可看工单编号、教室、上报/处理截止、维修人员姓名、问题描述、完工说明、评价和“处理记录”。同步中还显示尝试次数、最近错误和下次计划。页面约每 2 秒刷新同步详情，约 60 秒后停止自动刷新，改用详情“刷新”；后台仍会继续重试。多次失败显示“需要人工关注”时联系物业管理员，勿新建同一故障来代替恢复。完整交接和期限见 [报修闭环](workflows.md#repair)。

<a id="notifications"></a>
## 通知中心

**入口与使用者：** 学习空间 →“通知中心”，或右上角铃铛，路径 `/notifications`。所有用户看“我的通知”；有通知管理权限才出现“邮件送达管理”。

“我的通知”显示预约提醒、审批结果、维修进展等。点“查看业务”进入相关记录；点“已读”并确认后去掉未读标记。已读与邮件是否送达是两件事，不会停止发信。关联记录不可见时可能是权限已变，按提示联系管理员。

“邮件送达管理”可按“全部业务来源”“全部授权教室”“全部送达状态”筛选，查看尝试次数和最近错误。筛选状态为“待发送 / 发送中 / 重试中 / 已发送”；未成功记录可点“立即重试”，提示“已安排原记录重试”后刷新查看。连续失败 8 次后仍每 5 分钟重试，记录不会因此自动消失。

当前待发送记录的卡片标签可能显示“审批中”，这是与申请页共用标签的显示限制，**不需要审批邮件**；用“待发送”筛选确认，再按正常发送流程处理。邮件失败不影响已成功业务，本地邮件去 Mailpit 测试收件箱查看。处理顺序见 [通知与结果确认](workflows.md#notifications)。

<a id="display"></a>
## 教室签到屏幕

**入口与使用者：** 有该教室展示资格的工作人员，从“空间管理 → 教室与座位 → 管理教室 → 打开签到屏幕”进入，新标签页路径 `/display/:roomId`。无需手工拼接教室编号到地址。

页面显示教室名、日期、中国标准时间与当日编码，提示学生打开“我的预约”输入编码。编码按中国标准时间每天 00:00 换码；页面每分钟刷新，也可点“刷新编码”。跨天时先核对日期，学生必须使用本教室当天的码。

出现“无教室屏幕权限”或数据不可见，联系管理员确认专用展示权限及教室范围。普通学生不能在预约详情读取明码。这个功能验证持有当日码，不采集定位，也不等于物理到场证明。
