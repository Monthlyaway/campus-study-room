# 六项常见工作流

[使用手册](README.md) · [页面指南](pages.md) · [管理工作台](administration.md) · [常见问题](faq.md)

下面按完整任务说明“谁来做、在哪里做、成功后看什么”。本地演示角色的账号对应关系统一见 [演示账号](../development/demo-accounts.md)。多角色演练要切换账号，不能用同一个管理员代替所有人。

<a id="booking"></a>
## 1. 预约座位、签到与再次预约

前提：账号已启用，具有学生选座/预约资格；使用公共教室或本人所属院系允许的教室。

1. 打开“查找座位”。例如选择明天、09:00、2 小时；需要时筛选“校区”“楼宇”“教室”，或打开“仅带插座”，点击“查询可预约座位”。结果按教室展示当前可约座位。
2. 点击一个座位，在“确认预约”弹窗核对教室、座位号和 09:00–11:00 时段，再点“确认预约这个座位”。看到“预约成功，请按时到教室签到”，页面进入“我的座位预约”；新记录应为“待签到”，并有新预约编号。
3. 计划改变时，在开始时间前打开“查看详情”，点“取消预约”并确认；成功后为“已取消”，座位释放。09:00 起不能再主动取消这次 09:00 开始的预约。
4. 到教室查看当天签到屏的编码。打开“我的座位预约”对应记录，点“立即签到”，在“教室当日签到码”填入编码并点“确认签到”。09:00 开始的预约允许在 **09:00 ≤ 当前时间 < 09:15** 签到；09:15 整已经超时。成功提示“签到成功”，状态变为“使用中”。
5. 使用结束后系统处理为“已完成”。以后从该记录点“再次预约”，查找页只带入原教室/座位；重新选择新日期、时间并查询，正常提交后产生新编号，旧记录不变。

如果没有空位，先换时段或放宽插座/教室筛选。查询不保留座位，提交时可能已被他人占用；冲突时点“返回并重新选择”。同一人不能同时预约重叠时段，即使在不同教室。默认个人最长 4 小时，可由管理员调整；结束必须在未来 14 天内，且整个时段都开放。

未按时签到会释放座位，记录为“未签到”；该记录目前不自动剥夺预约资格。维修造成的“已取消”或“维修中断”不新增未签到违约，但此前已经成立的未签到历史不会被擦除。详情与日期筛选见 [我的座位预约](pages.md#reservations)。

<a id="application"></a>
## 2. 申请整间教室，由两人依次审批

前提：申请人已获得单独的“教室申请人”资格；另有覆盖相应院系/教室的院系审批员与教室审批员。申请人不能自批，两级不能由同一个人完成。

1. 申请人在“教室申请”点“申请教室”，选“使用日期”“开始时间”“使用时长”，点“查询可申请教室”，再点目标教室的“选择教室”。默认整室最长 8 小时，按当前页面上限与完整开放时段选择。
2. 填“用途标题”1–100 字、“用途说明”1–2000 字，确认教室与时段后点“提交教室申请”。看到“申请已提交，等待院系审批”；在“我的申请”查看“审批中”及“最晚审批时间”。
3. 院系审批员登录后在“教室申请 → 待我审批”打开“查看并处理”，核对用途、时段和当前步骤，点“通过院系审批”，可填不超过 500 字的审批意见，再确认。此时进入教室审批，整体仍是“审批中”，**尚不占用教室**。
4. 另一位合格教室审批员在“待我审批”处理第二步，点“通过教室审批”。确认成功后申请为“已批准”，整间教室的该时段才被占用；申请人可在详情“审批进度”看到两级意见和时间。审批员可在“我已处理”回看。
5. 任何一步不合适，审批员点“驳回”，填写 1–500 字“驳回理由”；申请变为“未通过”。需要修改申请内容时，申请人按允许状态“撤销申请”，再创建新申请，不能在原记录直接编辑。

审批截止取“创建后 24 小时”和“申请开始时间”中较早者，详情显示准确时刻；到截止不能再批准，最终为“已过期”。本人可撤销审批中申请；已批准申请本人撤销必须早于开始时间，之后需有范围的管理人员处理并填写原因。

第二级提交仍会检查资源；若资源冲突，本次不会留下批准或占用，刷新后检查当前状态。可以在截止前等冲突解除后再处理，也可驳回或由申请人撤销重建。不要让申请人凭一级通过就安排使用。标签页与失败处理见 [教室申请](pages.md#applications)。

<a id="repair"></a>
## 3. 报修、派单、维修、验收与评价

前提：报修人有该教室的报修资格，派单员覆盖该教室，维修人员账号有效；验收由报修人或有范围的物业管理员完成，实际维修人不得自验。

1. 报修人在“设施报修”点“上报故障”。选“故障教室”，填“哪里出了问题”1–100 字、“问题描述”1–2000 字，写清位置和现象。确认后在“我的报修”看到“待派单”和工单编号。
2. 派单员在“设施报修 → 工单管理”点当前任务按钮，选择“分配维修人员”或“更换维修人员”，在“维修人员”中选人并确认。工单变为“待维修”，详情出现维修人员姓名。开始维修前可重新派单，原人员随后失去这张任务的处理资格。
3. 被派维修人员在“我的维修任务”打开工单，点“开始维修”。先看到“正在暂停教室使用”；只有确认完成后变为“维修中”，才表示这张工单的教室下架已生效。不要把“已提交下架请求”当成下架完成。
4. 修复后，维修人员点“提交完工”，填 1–2000 字“维修处理情况”。确认后变为“待验收”，**座位仍保持下架**。
5. 报修人在“我的报修”，或合格物业管理员在“工单管理”，查看完工说明并实际核查。点“验收通过”可填意见；随后为“正在恢复教室使用”，等同步确认后才“已完成”。若问题仍在，点“验收不通过”，用 1–500 字说明仍存在的问题；状态回到“维修中”，继续下架，维修人处理后重新提交完工。
6. 工单“已完成”后，报修人点“评价维修”，选 1–5 分“满意度”，可写不超过 500 字补充评价。提交后显示评价，且只能提交一次、不能修改。

本人只可取消“待派单”的自己的工单；派单员可在授权范围取消“待派单”或“待维修”工单。页面“取消工单”要求填写原因。已开修、同步中、待验收不能用取消代替完整处理。

派单期限为上报后 24 小时，完工期限为首次派单后 48 小时；改派不延长。验收期限为本次提交完工后 48 小时；验收不通过后再完工，会产生新的验收期限。超时通知相关人员，不会自动验收或恢复教室。

同步详情会自动刷新一段时间，约 60 秒后提示手动刷新；后台重试仍继续。出现“需要人工关注”时联系物业管理员，有权限者可点“重试同步”，继续原工单。关闭一张工单只解除其自身影响；其他维修、预约、整室占用或管理员停用仍可能让教室不可约，旧取消记录也不会复活。参见 [设施报修](pages.md#repairs) 和 [同步问题](faq.md#sync)。

<a id="accounts"></a>
## 4. 开通账号，并限定申请或审批范围

前提：经授权的管理员能使用“账号与授权”与“角色与职责”；本人应知道这名成员需要的职责与范围。管理菜单不同并不意味着账号故障。

1. “账号与授权 → 创建账号”，填账号、初始密码、姓名、有效邮箱、所属院系；准备授予学生角色时同时填“学号（学生必填）”。确认后列表出现启用账号；此时还要授予业务角色。
2. 找到该账号，点“设置职责”，在“能做什么”选择已有职责，在“负责哪些对象”选择本人、院系、教室或全校等范围；多个职责分别添加，教室按名称与位置选择。
3. 例如给学生开整室申请资格，保留原学生绑定，再加“教室申请人”，范围用“本人”。给院系审批员选“院系审批员 → 指定院系”，选要负责的院系；给另一个教室审批员选“教室审批员 → 指定教室”，选目标教室。不要为了省事把每个人都设为“全校”。
4. 点“保存授权”，应看到“权限已更新，用户需重新登录”。提醒对方重新登录，检查是否出现申请按钮或正确的待审批记录；范围外记录不应因为另一个角色有广范围就混入。
5. 若没有适合的角色，可在“角色与职责”新建角色并“配置权限”，再回用户页绑定；单纯起一个“审批员”名字不会自动获得审批能力。详细操作见 [角色与职责](administration.md#roles)。

账号修改、角色/范围变化和重置密码可能使原会话失效，这是权限更新结果。最后一个有效系统管理员受保护。若绑定学生时提示缺学号，当前编辑账号弹窗不能补改学号，请联系维护人员核实开通资料，不要重复新建账号绕过提示。字段和管理弹窗冲突处理见 [账号与授权](administration.md#users)。

<a id="spaces"></a>
## 5. 开放教室、座位与签到屏幕

前提：教室与座位员有目标范围，具备教室签到展示权限；维护校区、楼宇或院系还需要账号管理权限。默认系统管理员不等于教室与座位员，可以由不同人员分工。

1. 在“教室与座位”先核对“校区”“楼宇”的上级资料已启用；缺失时由同时具备空间页面访问权与账号管理权的人员“添加校区”“添加楼宇”，楼宇要选所属校区；院系也由该权限组合的人员维护。仅有默认教室与座位员权限时，虽然可见校区/楼宇按钮，保存会被拒绝。
2. 回“教室与座位”，点“添加教室”，选楼宇，填教室编号、名称；“所属院系（留空为全校共享）”按实际用途选择。保存后列表应显示位置和共享范围。
3. 点该行“管理教室”，在“座位管理”点“新增座位”，填写座位编号并选“有插座”或“无插座”。保存后座位表出现启用座位；以后可用行内“插座”更新标记。
4. 点“开放时间”，在“每周开放时间”用“添加开放区间”设置星期、开始、结束，然后“保存”。每项是整点连续区间，同一天可多段但不能重叠。跨午夜如周一 22:00 到周二 02:00，要拆成周一 22:00–24:00 和周二 00:00–02:00。
5. 用有准入资格的账号去“查找座位”，选未来完整开放的时段并查询；能看到新座位才说明这些条件共同满足。仅创建了座位、尚未设置开放时段，不足以完成开放。
6. 授权人员回“管理教室”，点“打开签到屏幕”，在新标签页确认教室、日期和当日码正确。学生在自己的“我的座位预约”完成签到，不需要登录这个管理账号。

有有效预约、整室占用或维修封禁时，停用教室/相关座位或改开放规则可能被拒绝；先看该详情的“资源占用记录”，按原业务处理，不能在这里直接清除来源。启停保留历史；现有资源的编号和归属不能在“编辑名称”中迁移。完整子页见 [教室与座位](administration.md#spaces)。

## 6. 确认业务结果，处理未收信或网络中断

1. 提交后未收到邮件，先打开“我的座位预约”“我的申请”或“我的报修”，查看业务是否已经成功。邮件是提醒通道，发送失败不会撤销成功业务。
2. 打开“通知中心 → 我的通知”。点“查看预约”“查看申请”或“查看报修”进入相关详情；点“标记已读”后确认，只改变阅读标记，不会取消邮件发送。
3. 本机演示邮件到 Mailpit 测试收件箱查看，入口由 [当前实例](../operations/current-instance.md) 或维护者提供。不同环境的邮件入口可能不同，不能据个人外部邮箱没有信判断本地发信失败。
4. 有通知管理权限的人员进入“邮件送达管理”，按业务来源、授权教室和送达状态筛选。未发送成功的记录可“立即重试”；成功提示“已安排原记录重试”，随后刷新确认是否“已发送”。这一步不会重新创建预约、申请或报修。
5. 若业务弹窗明确提示“网络连接中断，结果尚未确认”，保持内容不变、不要关闭弹窗，恢复网络后点“重试原请求”。成功后核对同一业务编号。若已经刷新、关闭或退出而丢失原弹窗，先查列表确认结果，再决定是否发起新操作。
6. 如果提示数据或资源已变化（409），点“返回并重新选择”，看刷新后的记录再作决定；这与网络未确认的处理不同。管理页某些保存弹窗没有此按钮，按 [常见问题](faq.md#conflict) 关闭、刷新、重新打开。

邮件长期失败或同步长期未确认时，保留完整业务编号和请求编号交给维护人员，所需信息见 [报障方式](faq.md#support)。
